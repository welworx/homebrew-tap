# homebrew-tap

![Update formulas](https://github.com/welworx/homebrew-tap/actions/workflows/update-formulas.yml/badge.svg)

Personal Homebrew tap for welworx tools.

## Packages

**[flatex-fetch](https://github.com/welworx/flatex-fetch)** — download document-archive PDFs from the flatex.at broker portal

```
brew install welworx/tap/flatex-fetch
```

**[flatex-pdf-cli](https://github.com/welworx/flatex-pdf-cli)** — extract structured JSON from German flatexDEGIRO broker PDFs

```
brew install welworx/tap/flatex-pdf-cli
```

Formulas are checked daily and auto-bumped to each project's latest release.
